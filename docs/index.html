Install in under a minute

The Firmaradar Custom App is in pilot (limited public) and distributed via direct install URL. A directory listing depends on Make's review and approval.

🚀 Install Firmaradar Custom App in Make
1

Click the install button

The URL above opens Make.com with the Firmaradar app pre-loaded. Confirm install with your account.

2

Add your API key

Generate a key at firmaradar.no/min-side/api-keys and paste it into the Firmaradar connection in Make.

3

Drop a module into a scenario

Search for Firmaradar in the module picker. Pick a module like Get company or Check AML/PEP.

Modules for company intelligence workflows

The live app has 26 modules, including six hidden from the module picker. See the module reference for endpoints, access requirements and output conventions.

🔎 Search

  • Search companies — search by name, organization number, industry or municipality
  • Search persons — find role holders and shareholders by name

🏢 Company actions

  • Get company — core company profile
  • Get ownership — direct owners or holdings
  • Get roles — board, management and signing roles
  • Get financials — annual statement history
  • Get recent changes — company announcements
  • Get group public support — support across the group tree

⚖️ Risk and AML

  • Get risk signals — multi-source company indicators
  • Check company in difficulty — statutory distress classification
  • Check AML/PEP — named-person sanctions and PEP screening
  • Start AML report — asynchronous company report
